# 🧮 Nova Calculator

A modern, responsive calculator built using **HTML, CSS, and JavaScript**.
Nova Calculator provides a clean and interactive user interface with real-time calculations, keyboard support, calculation history, and dark/light themes.

## ✨ Features

* ➕ Addition
* ➖ Subtraction
* ✖️ Multiplication
* ➗ Division
* 📊 Percentage calculations
* 🔄 Positive/negative toggle
* ⌫ Delete individual digits
* 🗑️ Clear calculator
* ⌨️ Full keyboard support
* 🕘 Calculation history
* 💾 History saved using Local Storage
* 🌙 Dark mode
* ☀️ Light mode
* 📱 Responsive design
* ⚡ Real-time display updates
* 🚫 Division-by-zero protection
* 🎨 Modern glassmorphism-inspired interface
* ✨ Smooth hover and button animations

## 🛠️ Technologies Used

* **HTML5** — Structure and semantic markup
* **CSS3** — Styling, responsive layout, animations, and themes
* **JavaScript (ES6+)** — Calculator logic and interactivity
* **LocalStorage API** — Persistent calculation history
* **Google Fonts** — Inter typography

## ⌨️ Keyboard Shortcuts

| Key         | Action                |
| ----------- | --------------------- |
| `0 - 9`     | Enter numbers         |
| `+`         | Addition              |
| `-`         | Subtraction           |
| `*`         | Multiplication        |
| `/`         | Division              |
| `%`         | Percentage            |
| `.`         | Decimal               |
| `Enter`     | Calculate result      |
| `Backspace` | Delete                |
| `Escape`    | Clear / Close history |
| `C`         | Clear calculator      |

## 🚀 How to Run

### 1. Clone the repository

```bash
git clone https://github.com/abdullah785g/codealpha-calculator.git
```

### 2. Open the project

Navigate into the project folder:

```bash
cd codealpha-calculator
```

### 3. Run the calculator

Open `index.html` directly in your browser or use **VS Code Live Server**.

No backend or additional dependencies are required.
